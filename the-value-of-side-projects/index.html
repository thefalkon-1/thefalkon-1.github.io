The Value of Side Projects

Side projects have been one of the most valuable investments in my career. Here's what I've learned about making them worthwhile.

Learning by Doing

The best way to learn a new technology is to build something with it. Reading documentation only goes so far—real understanding comes from hitting roadblocks and solving them.

My side projects have taught me:

  • How to scope work realistically
  • When to use (and not use) new technologies
  • The importance of finishing things

No Stakeholders

Unlike work projects, side projects have no stakeholders except yourself. This freedom is both liberating and dangerous.

Liberating because you can experiment freely. Dangerous because there's no external pressure to finish.

Tips for Success

After many abandoned projects, here's what works for me:

  1. Start small - Your first version should be embarrassingly minimal
  2. Ship early - Deploy something, even if it's basic
  3. Time-box - Give yourself a deadline
  4. Solve your own problems - Projects with personal utility are more likely to get finished

This Blog

This blog itself is a side project. Setting it up forced me to learn about static site generators, CSS layouts, and web deployment—skills that have direct professional value.
